# 🐍Snake Game 🐍
</div>

**In Holberton school we are moving from learning the C lanaguge into Python, therefore the snake is eating all C's :)** 

This is a simple snake game created using Pygame. The snake eats the "C"s while navigating through the maze. The game ends if the snake collides with the walls or itself.

## 🕹️How to Play🕹️:
- Use the arrow keys to move the snake.
- Eat the "C"s to score points.
- Avoid running into the snake's body or the maze walls.
